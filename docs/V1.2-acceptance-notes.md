## 使用
在项目目录打开普通 PowerShell（无需管理员）：

```powershell
cd 'D:\Creator\视频下载\VideoLibrary_Windows_v1.0_fixed\video-library-mvp'
powershell -NoProfile -File .\manage.ps1 -Action Shortcut
powershell -NoProfile -File .\manage.ps1 -Action Open
```

Shortcut 创建桌面「VideoLibrary 视频保存」，双击通过隐藏启动脚本启动服务并打开网页。Open 同样功能。Start 只启动后台，不开网页。start.bat 保留为可见控制台诊断入口，不再自动开浏览器。服务重复启动时由端口绑定防止第二实例；管理脚本先检查本项目页面，其他程序占用端口则报错。

```powershell
powershell -NoProfile -File .\manage.ps1 -Action Status
powershell -NoProfile -File .\manage.ps1 -Action Stop
powershell -NoProfile -File .\manage.ps1 -Action EnableStartup
powershell -NoProfile -File .\manage.ps1 -Action DisableStartup
```

只有显式运行 EnableStartup 才注册当前用户、普通权限、登录触发的任务。DisableStartup 删除该任务，不强杀下载。网页「保存位置与服务」也可退出。若组织策略禁止脚本或任务计划，请保留策略，使用 start.bat 诊断；不要关闭防护。后台启动若失败，open.vbs 提示使用 start.bat 查看错误。

## 下载与设置
默认目录 D:\Creator\视频下载\下载成品。展开「保存位置与服务」，输入完整目录并保存；写入项目 settings.json，重启保留。不会移动原目录文件。下载前创建目录、测试写入并要求至少 1 GB 可用空间；这不是视频大小保证，大文件仍可能耗尽磁盘。任务开始后冻结目录设置，成品名加任务随机后缀避免覆盖。完成信息通过 ffprobe 读取真实分辨率；未检测到则明确显示未能检测。打开文件夹在运行服务的 Windows 电脑上执行。

默认匿名识别，遇 YouTube 验证才勾选 Firefox 登录会话重新识别原链接。Cookies 不导出到项目，不打印 yt-dlp 原始诊断，不自动授权。保留现有 Deno 自动发现方式。

读取剪贴板按钮只在操作时读取；自动读取需勾选同意，仅页面打开/重新聚焦尝试一次，无定时监控。只提取支持域名链接，其他文字不传服务器、不持久化。重复链接在当前页面会话内去重；权限拒绝时可手动粘贴。不会自动识别或下载。

## Windows 验收
1. 先关闭旧版服务（原控制台 Ctrl+C），运行 `.venv\Scripts\python.exe -m py_compile app.py`；运行 `node --check static/app.js`、`node check-v12.cjs`（若安装 Node）。
2. start.bat 启动，手动访问 http://127.0.0.1:8765；网页退出。再用 Start 后台启动，确认没有黑窗/浏览器；重复 Start，确认只一项监听：`Get-NetTCPConnection -LocalPort 8765 -State Listen`。Status、Stop 验证退出。
3. Shortcut 后双击桌面快捷方式验证启动并打开网页。EnableStartup 后注销登录，确认后台运行且浏览器未打开；DisableStartup 后再次登录确认不启动。上述均由用户主动执行。
4. 改成新的测试目录，重启服务核对保留；无效路径、无写权限目录、低于 1 GB 磁盘应报中文错误。确认原目录已有文件不变。
5. 复制 B站、YouTube、抖音分享文字，点击读取，验证只提示不下载；重复聚焦无反复提示；拒绝权限、无链接时有反馈；手动粘贴仍可识别。
6. 用本人有权保存的 B站链接匿名识别及下载；YouTube 先匿名，要求验证时勾选 Firefox 后重新识别，无需重新粘贴；选择最高画质并确认输出真实分辨率和音频。用 `ffprobe -v error -show_streams "成品完整路径"` 验证视频/音频流。与 v1.1 已成功的同一链接比较。
7. 抖音若返回 403，应显示简洁中文拒绝访问，不重试绕过。无效/失效链接识别失败、下载过程中断网失败，再重试，确认没有旧 100% 进度。
8. 桌面浏览器开发者工具模拟 360、390、768、1366 像素宽，检查输入、按钮、目录长路径和完成信息无横向溢出。因只监听回环，手机实机不能访问电脑服务；使用模拟宽度。
9. API 安全：`curl.exe -i http://127.0.0.1:8765/api/config` 无令牌应 403；浏览器正常页面请求通过；外部 Origin 即使附令牌也应拒绝。
