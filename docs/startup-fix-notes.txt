在普通 Windows PowerShell 5.1 中执行：

cd 'D:\Creator\视频下载\VideoLibrary_Windows_v1.0_fixed\video-library-mvp'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Start
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Start
Get-NetTCPConnection -LocalPort 8765 -State Listen
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Open
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Shortcut

预期：已有手动启动服务时直接连接，不启动第二实例；服务关闭时 Start 隐藏启动且不开浏览器；Open 和 start.bat 打开浏览器。重复 Start 仅一个监听进程；其他服务占用端口则明确报错。双击新桌面快捷方式验证同样行为。

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Stop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\manage.ps1 -Action Status

下载期间 Stop 应拒绝退出。正常退出后再次双击快捷方式验证冷启动。

日志：项目 logs\startup.log 记录启动调用和管理错误；每次启动独立的 *.stdout.log、*.stderr.log 保留 Python 启动错误。不会自动删除旧日志。若后台超时，先检查日志和端口，脚本不会强杀可能仍在运行的进程。不要公开分享未经检查的完整日志。

ExecutionPolicy Bypass 仅作用于该次 PowerShell 子进程；没有 Set-ExecutionPolicy，不永久修改策略，不修改安全防护；组织组策略仍可能限制脚本执行。未启用自启；仅明确执行 EnableStartup 才注册任务。原有已注册任务不会自动更新；如需要更新其调用参数，请用户明确重新运行 EnableStartup。
